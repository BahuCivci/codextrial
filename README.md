# codextrial

This repository contains two simple Python applications:

1. **Flask Temperament Quiz** (app.py) - A web app that helps you discover which of the four classic temperaments best describes you.
2. **Pygame Tetris Game** (app2.py) - A basic implementation of Tetris that you can play locally.

## Running the temperament quiz

1. Install dependencies:
   ```bash
   pip install Flask
   ```
2. Start the development server:
   ```bash
   python app.py
   ```
3. Open your web browser and go to `http://localhost:5000` to answer the questions and view your temperament result.

## Running the Tetris game

1. Install dependencies:
   ```bash
   pip install pygame
   ```
2. Run the game:
   ```bash
   python app2.py
   ```
