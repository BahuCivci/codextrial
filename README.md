# codextrial

This repository contains a small Flask application that generates a basic weekly diet plan. The interface uses TailwindCSS for a clean design and includes pages for Home, Diet Plan, About and Contact.

## Running the app

1. Install dependencies:
   ```bash
   pip install Flask
   ```
2. Start the development server:
   ```bash
   python app.py
   ```
3. Open your browser at `http://localhost:5000`.

The diet plan and nutritional calculations are provided for general informational purposes only and are not a substitute for professional medical advice.
